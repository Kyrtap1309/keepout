# The dashboard's seed

The CDMs of the dashboard's demo; [The dashboard](../../docs/dashboard.md#the-demo)
says how to run it and what it shows.

Generated by `tools/dashboard_seed.py`; do not edit the CDM files.
`uv run python tools/dashboard_seed.py --check` (run in CI) fails when they
are out of date.

- `cdms/*.kvn`: the CCSDS CDMs of keepout's example synthetic operator. The
  fleet of `examples/synthetic-operator/fleet.toml` is screened against the
  frozen public GP catalog of 2026-10-06 (`tests/screening/data/`, see its
  `NOTICE`) over the week of its SOCRATES report, as on the page [Synthetic
  operator on public data](../../docs/synthetic-operator.md), but as an
  operator receives updates: every 12 hours over the first two days of the
  week (2026-10-06 00:00, 12:00, 2026-10-07 00:00 and 12:00 UTC), each run
  issuing a CDM, created at its own start, for every approach still ahead.
  The 12 approaches get 37 CDMs, up to 4 each.
  Every covariance is keepout's model of GP element set errors (an age
  model), not orbit determination, and the messages say so in their
  comments. The model's covariance depends on the element set's age at
  TCA, not on when the CDM is issued, so an event's CDMs give the same Pc.
  The real values are rounded to 7 significant digits.
- `settings.toml`: the operator settings the seed is assessed with,
  keepout's defaults. The CDMs give each object's hard-body radius (`HBR`).

CARA's Metop-B test CDM (from NASA's CARA Analysis Tools) is not
redistributed. `uv run python tools/dashboard_seed.py --cara` adds it as
`cdms/<id>.cdm` from keepout's local cache (`keepout fetch cara` downloads
it), and git ignores that file. A `*.kvn` glob leaves it out: add
`examples/dashboard/cdms/*.cdm` to `keepout store add`. It has no `HBR`
keyword (its hard-body radius, 10 m, is only in a comment), so set
`hbr_m = 10.0` under `[pc]` in the settings: without it, `keepout store
add` skips its Pc, the dashboard shows it as not computed, and the refresh
job (the Compute button) fails for want of a hard-body radius.
